Descreva com suas palavras o calculo solicitado no enunciado.

O cálculo solicitado consiste em multiplicar o valor da compra pela quantidade de pontos recebidos por real gasto. Por exemplo, se a compra foi de R$ 120,00 e o cliente recebe 2 pontos por real, o cálculo será 120 × 2 = 240 pontos. O servidor realiza esse cálculo e envia o resultado de volta para o cliente.

Cole aqui a saida apresentada ao executar o cliente. 

Pontos recebidos: 240

1.Em qual programa o código foi executado?
O código foi executado no Visual Studio Code (VS Code), utilizando o Python 3.13 pelo terminal integrado.

2.Qual programa iniciou a solicitação?
O cliente (cliente.py) iniciou a solicitação. Ele se conecta ao servidor e chama a função calcular_pontos(120, 2). O servidor (servidor.py) recebe a solicitação, realiza o cálculo e devolve o resultado para o cliente.

3.O que aconteceria com o cliente se o servidor estivesse desligado?
Se o servidor estivesse desligado, o cliente não conseguiria estabelecer a conexão com ele. Nesse caso, ocorreria um erro de conexão
